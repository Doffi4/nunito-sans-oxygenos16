# Nunito font payload

The ZIP contains the original Google Fonts Nunito variable fonts:

- `Nunito-VF.ttf` — upright
- `Nunito-Italic-VF.ttf` — italic

Source: https://github.com/google/fonts/tree/main/ofl/nunito

License: `LICENSES/OFL.txt` in the repository and module ZIP.
The font binaries are not modified. Their `wght` axis runs from 200 to 1000;
Android weight 100 is approximated by 200, while weight 900 uses axis 900.
The two build variants only change the XML axis used for Android weight 400.
